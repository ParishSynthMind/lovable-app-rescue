# The prompt given to Lovable (free plan, one message)

Typed into lovable.dev exactly as below, the way a small business owner would write it.

> Build a "Client Request Portal" for a small web design agency. Clients sign up and log in with email and password. A signed-in client can submit a request (title, description, category: bug, change, or question, and urgency: low, normal, or high) and sees a list of their own requests with the status (new, in progress, done). Agency staff are users with the role "admin": they see a dashboard of every request from every client, can filter by status, change the status, and add an internal note the client never sees. Use Supabase for login and the database. Clean, modern, professional design.
